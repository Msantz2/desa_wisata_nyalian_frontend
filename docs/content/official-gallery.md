## 1. Usage Types

Every planned image is tagged with how it will be used on the site, so a single photography session can be planned efficiently:

| Usage | Where it appears | Typical orientation |
|---|---|---|
| **Hero** | Top banner of a destination/package/home/about page | Wide/landscape, high resolution |
| **Thumbnail** | Destination/package cards in listing grids and homepage previews | Landscape, crops well to a card aspect ratio |
| **Gallery** | Detail-page image gallery/lightbox | Mixed orientation acceptable |
| **OG** | Social share preview (Open Graph/Twitter Card) | Landscape, text-safe (avoid important detail at the very edges) |

A single photo can often serve multiple usages (e.g. a strong hero shot can double as the OG image) — this is noted per entry where applicable.

## 2. Naming & Alt Text Convention (Recap)

Per `official-seo-content.md` Section 7: filenames are descriptive, lowercase, hyphenated, and keyword-relevant (e.g. `puri-agung-nyalian-courtyard.jpg`, never `IMG001.jpg`). Alt text describes what is actually shown, using the destination/package name naturally. This document proposes specific filenames and alt text per shot below — treat them as strong drafts, adjustable once the actual photo is in hand.

## 8. Consent & Sensitivity Protocol

| Subject | Default Rule |
|---|---|
| Unpeopled landscapes, architecture exteriors, trail scenery | Safe to capture without individual consent (site/community access coordination still applies) |
| Named artisans, homestay hosts, guides | Requires explicit individual consent before any identifiable photo is published, per `official-umkm.md` |
| Puri Agung Nyalian interior / family areas | Requires prior coordination with the puri; do not treat as open-access |
| Any moment of active worship (melukat, prayer) | Requires consent of the person(s) photographed; avoid sensationalized framing |
| Tari Baris Tentara, Sang Hyang Jaran Mesiram (any part of the ritual) | **Prohibited by default.** Only permitted with explicit, occasion-specific community/adat consent. Never use substitute/stock imagery from other villages |
| Children | Additional caution and guardian consent required; prefer not to feature identifiable children unless explicitly cleared with parents/guardians and Pokdarwis |
